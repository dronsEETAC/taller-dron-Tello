# Intalaciones necesarias
1. Git https://git-scm.com/install/windows
2. Python version 3.11.9 https://www.python.org/downloads/release/python-3119/
3. Pycharm version 2025.1.6.1 https://www.jetbrains.com/pycharm/download/other/#releases-2025
4. En el interprete de python instalar las librerias siguientes:   
   djitellopy   
   mediapipe (version 0.10.21)   
   ultralytics    
   torch   
   seaborn   
   tqdm   
5. Si al ejecutar el programa cuerpo.py o el programa detectarObjetos.py aparecce este error:    
       
       ImportError: DLL load failed while importing _framework_bindings:     
       The specified module could not be found.      

   instalar Microsoft Visual C++ Redistributable 2015–2022 (x64) https://learn.microsoft.com/es-es/cpp/windows/latest-supported-vc-redist?view=msvc-170
